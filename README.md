### Engineering Focus

I am a Software Engineer and ML Engineer focused on building practical AI systems that move from prototype to production. I enjoy the whole stack around modern ML products: data pipelines, model integration, backend services, evaluation, deployment, and the reliability work that makes LLM features useful in real workflows.

- **LLM Applications:** Building RAG, agentic workflows, tool-calling systems, and product-facing AI features.
- **ML Infrastructure:** Designing training, evaluation, and inference pipelines with reproducibility and observability in mind.
- **Backend Systems:** Developing APIs, services, queues, storage layers, and integrations that support ML-powered products.
- **Evaluation & Deployment:** Creating regression suites, quality checks, monitoring, and serving paths for reliable model iteration.
